# TFY4195 — Optikk

Interaktiv studieguide for [TFY4195](https://www.ntnu.no/studier/emner/TFY4195)
ved NTNU: **[optikk.martinsundal.no](https://optikk.martinsundal.no)** — moduler med quiz, flashcards,
formelsamling og begreper.
Emnet er fullført — guiden vedlikeholdes ikke lenger.

Bygget på [StudyCompanion](https://github.com/MartinSA04/StudyCompanion);
dette repoet inneholder kun innhold (`content/`).

## Kjør lokalt

```bash
pnpm install
pnpm dev
```
