# TFY4195 Optikk

Interaktivt kompendium i [TFY4195](https://www.ntnu.no/studier/emner/TFY4195) ved NTNU:
moduler med quiz, flashcards, formelsamling og begreper. Les det på
**[optikk.martinsundal.no](https://optikk.martinsundal.no)**.

Bygget på [StudyCompanion](https://github.com/MartinSA04/StudyCompanion);
dette repoet inneholder kun innhold (`content/`).

## Kjør lokalt

```bash
pnpm install
pnpm dev
```
